# 描述

配置数据集owasp java bench

# 步骤

1、克隆仓库

https://github.com/OWASP-Benchmark/BenchmarkJava.git
1

2、运行构建脚本

cd BenchmarkJava
./runBenchmark.sh
1
2

看到“[INFO] Press Ctrl-C to stop the container...”这个信息就证明启动成功了

3、访问测试网站

https://localhost:8443/benchmark/
1

如果是在本地电脑访问，可以建立ssl通道，在本地电脑命令行执行下列命令

 ssh -L 8443:localhost:8443 <username>@<remote.ip.xx.xx>
