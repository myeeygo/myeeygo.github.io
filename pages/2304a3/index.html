从服务器下载文件

# 问题描述

想要从云服务器下载文件，虽然可以使用vscode图形界面右键下载，但是也有时需要命令行操作

# 描述

1、记录文件在服务器中的路径，如果不清楚，可以使用pwd命令确认父文件夹的路径。

2、本地打开powershell或者git bash等命令行终端，输入以下命令

scp -P <portNUm> <userName>@<remoteIpAddress>:<remoteFilePath>  <localPathToSave>
# 一个例子
scp -P 22 ubuntu@101.43.87.xxx:/home/ubuntu/crypto_tools/xxx.zip ./xxx.zip
# 如果想要使用ssh密钥文件，可以通过 -i 参数指定，不过默认会去 ~/.ssh 文件夹里面寻找。例子如下
scp -P 22  -i ~/.ssh/keyPass.pem ubuntu@101.43.87.xxx:/home/ubuntu/crypto_tools/xxx.zip ./xxx.zip
# 如果操作对象是目录，记得加上 -r 参数
