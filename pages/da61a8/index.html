    Virtualbox虚拟机扩容

    # 问题描述

    使用的virtualbox虚拟机-ubuntu 22.04 空间不够了，需要进行扩容

    # 解决方法

    首先关闭ubuntu虚拟机，打开virtualbox界面左上角的“管理”，选择“虚拟介质管理”，点击对应的vid文件（具体的对应文件名称在“设置”-“存储”中可以查看），在下面调整大小。

    接下来在ubuntu系统内部进行调整，将扩容的空间进行挂载。

    首先通过以下命令查看磁盘和分区状态

    lsblk
    1

    接下来通过以下命令查看空闲空间

    sudo parted /dev/sda print free
    1

    安装growpart工具

    sudo apt install cloud-guest-utils
    1

    扩展分区

    sudo growpart /dev/sda 3
    1

    扩展文件系统

    sudo resize2fs /dev/sda3
    1

    验证结果

    df -h /
df -h
