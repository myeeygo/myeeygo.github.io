# 描述

部署并使用工具cryscanner

# 前言

这个工具完成的不是很好，代码中有必须进行修改的地方，否则无法正常运行。此外，给的例子中，配置文件也需要修改，否则无法正常运行。

# 步骤

# 部署

1、克隆这个仓库

git clone https://github.com/amitsirius/cryscanner.git
1

2、修改其源代码

# 文件log_scanner
# log_scanner.py文件中

# 开头部分添加以下代码
import re

# def __parseObjects(self, obj):函数中
# 删掉以下两行
fname_t = Word(printables) + Suppress(Literal('('))
fname = fname_t.parseString(obj[0])[0]
# 修改为以下代码
        fname = None
        header = obj[0].strip()
        match = re.search(r'\bin\s+([A-Za-z_][A-Za-z0-9_]*)\s*\(', header)
        if match:
            fname = match.group(1)
        else:
            match = re.match(r'([A-Za-z_][A-Za-z0-9_]*)\s*\(', header)
            if match:
                fname = match.group(1)
        if fname is None:
            print(f"[ERROR]: unable to parse function header: {header}")
            return

# 运行

1、创建可运行例子

首先编译一个包含密码学调用的程序，以tests/aes_encryption/aes_example.c为例子

gcc -g -o aes_example aes_example.c -lcrypto
1

生成了 aes_example

2、执行gdb调试，生成log文件

接下来执行

 gdb -q aes_example testMessage 
 # 如果程序需要输入参数，可以使用以下命令
 gdb --args yourExeFile arg1Babala arg2
1
2
3

在gdb命令行中，依次输入

# gdb命令行中输入
source debug_lib.py 
simple_command
1
2
3

输出会被保存到 log.txt 中

如果想要直接一条命令执行，中间不输入其他命令，也可以执行下面的命令

gdb -q \
    -ex 'set debuginfod enabled on' \
    -ex 'set pagination off' \
    -ex 'source debug_lib.py' \
    -ex 'simple_command' \
    -ex 'quit' \
    --args ./aes_example testMess
